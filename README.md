# Cybersecurity Awareness Prediction

A Streamlit application that predicts cybersecurity awareness levels using a frozen Random Forest machine-learning model.

## Model
- Algorithm: Random Forest
- Predictors: 11
- Recorded test accuracy: 68.85%

## Run locally
Install the dependencies with `pip install -r requirements.txt`, then run `streamlit run app.py`.

The raw research dataset should not be published in a public repository.
