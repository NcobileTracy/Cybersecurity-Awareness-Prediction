About the Project

Cybersecurity awareness is important because people use digital devices and the internet for learning, communication, and accessing online services. However, many users may not recognise cybersecurity threats or understand how their online behaviour can affect their digital safety.

This project investigates how machine learning can be used to predict the cybersecurity awareness level of university students. An interactive web application was developed to collect information about a user's digital habits, cybersecurity practices, and personal background. A trained machine learning model then predicts whether the user's cybersecurity awareness level is Low, Medium, or High.

The project forms part of ICT Honours research and combines machine learning techniques with practical web application development.

Project Objectives

The main goals of this project are to:

Develop a machine learning model that predicts cybersecurity awareness levels.
Explore how selected personal and cybersecurity-related factors are linked to awareness levels.
Create a web application that allows users to complete a short questionnaire.
Display prediction results in a simple and understandable way.
Provide general cybersecurity guidance based on the predicted awareness level.
How the Application Works

Users complete a questionnaire about their background and cybersecurity practices. The questions cover areas such as age, education, field of study, internet usage, digital skills, device protection, and awareness of cybercrime threats.

The application processes the responses and sends them to a trained Random Forest model. The model predicts a cybersecurity awareness category, which is presented together with visual results and practical cybersecurity recommendations.

The prediction is an estimate generated by the model. It is not a formal cybersecurity assessment and does not guarantee how a person will behave online.

Machine Learning Approach

A Random Forest classifier was used for the cybersecurity awareness prediction task. The model was trained on a cybersecurity awareness dataset and evaluated using a separate test dataset and cross-validation techniques.

Evaluation Results
Evaluation Measure	ResultTest Accuracy	68.85%
Mean Cross-Validation Accuracy	65.92%
Cross-Validation Standard Deviation	2.52 percentage points

These results represent the performance achieved during model evaluation. They do not guarantee that every prediction made by the application will be correct.

Running the Project Locally

To run the application locally, ensure that Python and Git are installed on your computer.

Clone the repository:

git clone https://github.com/NcobileTracy/Cybersecurity-Awareness-Prediction.git
cd Cybersecurity-Awareness-Prediction


Install the required packages:

pip install -r requirements.txt


Launch the application:

streamlit run app.py


Streamlit will provide a local URL that can be opened in a web browser.

Data and Privacy

The original research dataset is not included in this public repository. The repository contains only the application files required for deployment and demonstration purposes.

Anyone wishing to reuse the project should review the permissions and conditions associated with the original dataset before using or sharing it. The application should also be used responsibly when collecting information from users.

Limitations

The model's predictions depend on the quality, size, and characteristics of the training dataset. Performance results may vary for different universities or populations.

The application predicts a cybersecurity awareness category based on the information provided by the user. It does not directly measure a person's ability to identify every cybersecurity threat and should not be considered a definitive assessment of cybersecurity knowledge.
